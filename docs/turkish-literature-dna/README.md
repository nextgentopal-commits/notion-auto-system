## 1. Zweck

Dieses Paket erschließt türkische Literatur als unterscheidbare Denk-, Emotions-, Körper-, Sprach-, Form-, Raum- und Gesellschaftsarchitektur. Es dient der quellenkritischen Analyse und der eigenständigen DEJÀ-VU-3-Transformation.

Es ist weder:

- eine Sammlung nachzuahmender Autorenstimmen,
- ein Gedicht-Dump,
- ein Zitatarchiv,
- ein pauschaler „türkischer Stil“,
- noch eine Gleichsetzung türkischer Literatur mit Hüzün, Sufismus oder Istanbul.

## 2. Kanonische Formel

```text
Person → materielle Wirklichkeit → Konflikt → Wahrnehmung → Emotion
→ Körper/Handlung → Werk-/Traditionsanker → Denkmodus → Perspektive
→ Rhetorik/Form → Gegenkraft → neue Erkenntnis → Output → Validierung
```

Für Transformationen gilt:

- **Gold:** ein führender Denk-/Emotionsmechanismus,
- **Silber:** eine kontrastierende Form- oder Perspektivlogik,
- **Bronze:** höchstens ein Akzent in Rhythmus, Raum oder Bild.

Mechanismen werden kombiniert, niemals Prozentanteile von Autoren.

## 4. Vier getrennte Wissensschichten

| Schicht | Bedeutung | Darf im Output erscheinen? |
|---|---|---|
| Fakt | belegbare bibliografische/historische Aussage | ja, mit Quelle |
| Interpretation | begründete Lesart | ja, als Interpretation markiert |
| Abstraktion | übertragbarer, nicht schützbarer Mechanismus | ja, als DNA-Mechanismus |
| Transformation | neues DEJÀ-VU-3-Werk | ja, ohne falsche Zuschreibung |

Keine Schicht darf still in eine andere umbenannt werden.

## 5. Domänentrennung

Literatur, türkische/kulturelle DNA, Film, Psychologie, Philosophie, visuelle Gestaltung, Archiv und Produktion bleiben getrennte Bibliotheken. Verbindungen werden über referenzierte Knowledge Nodes hergestellt; es entstehen keine neuen Bibliothekstypen.

Türkische Literatur liefert beispielsweise einen Mechanismus für innere Zeit. Die visuelle Bibliothek entscheidet getrennt, wie Zeit im Raum sichtbar wird. Die Psychologiebibliothek darf daraus keine Diagnose ableiten. Die Produktionsbibliothek wählt erst danach das Medium.

## 7. Betriebsstatus

Sofort einsetzbar sind die Architektur, Emotions-/Denk-/Formtrennung, Quellen-Gates, sechs validierungsnahe Profile und das GitHub-Quellenrouting.
