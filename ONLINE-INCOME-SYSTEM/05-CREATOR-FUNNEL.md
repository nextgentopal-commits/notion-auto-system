# 05 CREATOR FUNNEL

## Ziel
Aus Reichweite systematisch Interessenten, Käufer und Wiederkäufer entwickeln.

## Funnel
TikTok / Social Content -> Profil / Link -> Landingpage -> kostenloser Mehrwert oder Produkt -> E-Mail / Community -> Folgeangebot

## Bausteine
- Hook-Content
- klare Produktbrücke
- Landingpage
- Lead-Magnet optional
- E-Mail-Nachfasslogik
- Produktangebot
- Wiederkaufslogik

## Prüfregeln
- kein aggressiver Verkauf
- Content muss eigenständig wertvoll bleiben
- jede Stufe messbar machen
- möglichst wenig Reibung zwischen Content und Kauf

## Nächster Test
Einen bestehenden Content-Typ einem konkreten Produkt und einer einzigen Zielaktion zuordnen.
