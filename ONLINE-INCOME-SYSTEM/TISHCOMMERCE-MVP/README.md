# TISHCOMMERCE MVP

## Zweck
Minimaler digitaler Shop-MVP auf Basis der TishCommerce-Architektur.

## Phase 1
- keine OpenAI-API
- ein digitales Produkt
- deutsche Oberfläche
- Testzahlung zuerst
- PDF-Auslieferung nach erfolgreicher Zahlung
- keine unnötigen Zusatzsysteme

## Ziel-Flow
TikTok -> Produktseite -> Checkout -> Testzahlung -> Bestätigung -> PDF-Download

## Technische Basis
Referenzprojekt: tishonator/TishCommerce

Wichtige Eigenschaften der Referenz:
- Next.js / TypeScript
- Stripe und PayPal
- digitale Downloads
- JSON-basierte Produktkonfiguration
- keine Datenbank erforderlich

## MVP-Regel
Erst wenn der komplette Kauf- und Downloadfluss mobil fehlerfrei funktioniert, wird erweitert.

## Recht / Lizenz
Die TishCommerce-Lizenz und Attribution müssen vor öffentlichem Deployment geprüft und eingehalten werden. Die Referenz verlangt bei öffentlicher Nutzung einen sichtbaren Powered-by-TishCommerce-Hinweis, sofern keine abweichende kommerzielle Lizenz vorliegt.
