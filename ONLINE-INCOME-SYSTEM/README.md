# ONLINE-INCOME-SYSTEM

Ziel: Seriöse Online-Einnahmequellen systematisch prüfen, priorisieren und in kleine Tests überführen.

## Bereiche

1. Digital Products
2. Membership
3. Affiliate
4. Print-on-Demand
5. Creator Funnel
6. Own Store
7. Automation
8. Analytics

## Priorität

1. Digitale Produkte
2. Membership / Community
3. Creator Funnel
4. Affiliate als Ergänzung
5. Print-on-Demand später
6. Eigener Shop erst bei ausreichender Traktion

## Prüfregeln

- Kein Crypto-/Trading-Bot als Einkommensmodell.
- Keine Spam-Automation.
- Keine "Money Printer"-Versprechen.
- Erst Nachfrage und Verkauf testen, dann Technik ausbauen.
- Möglichst niedrige Fixkosten.
- Systeme müssen mit bestehendem Content nutzbar sein.

## Arbeitsweise

Jeder Fund wird bewertet nach:
- Startkosten
- technischem Aufwand
- Zeit bis zum ersten Test
- Automatisierbarkeit
- Skalierbarkeit
- Plattformabhängigkeit
- Passung zum bestehenden Content
- realistischem Erlösweg
